=======================================================
  FILE2LINK BOT — CLOUDFLARE SETUP GUIDE
  Complete this after the bot is running on Replit
=======================================================

PREREQUISITES:
- Bot is live at yourproject.replit.app
- You have a domain (free from porkbun.com or namecheap.com)
- Cloudflare account (free at cloudflare.com)

-------------------------------------------------------
PART 1: ADD YOUR DOMAIN TO CLOUDFLARE
-------------------------------------------------------

1. Go to cloudflare.com → Add a Site → enter your domain
2. Select Free plan
3. Cloudflare will scan your DNS — delete any existing records
4. Add ONE record:
   Type: CNAME
   Name: @ (or www)
   Target: yourproject.replit.app
   Proxy: ON (orange cloud — IMPORTANT)
5. Update your domain's nameservers to Cloudflare's (shown in dashboard)
6. Wait 5–30 minutes for propagation

-------------------------------------------------------
PART 2: SSL/TLS SETTINGS
-------------------------------------------------------

Dashboard → SSL/TLS:
- Mode: Full (strict)  ← NOT Flexible
- Always Use HTTPS: ON
- HTTP Strict Transport Security: ON, max-age=31536000
- Minimum TLS Version: TLS 1.2
- TLS 1.3: ON

-------------------------------------------------------
PART 3: SPEED SETTINGS
-------------------------------------------------------

Dashboard → Speed → Optimization:
- HTTP/2: ON
- HTTP/3 (QUIC): ON
- 0-RTT Connection Resumption: ON
- Brotli: ON
- Early Hints: ON

-------------------------------------------------------
PART 4: CACHE RULES
-------------------------------------------------------

Dashboard → Caching → Cache Rules → Create rule:

RULE 1 — Cache file downloads:
  Name: Cache Media Files
  When: URI Path matches regex  ^/[a-zA-Z0-9_-]{6}\d+
  Then: Cache eligibility = Eligible for cache
        Edge TTL = Override → 24 hours
        Browser TTL = Override → 1 hour

RULE 2 — Cache stream pages:
  Name: Cache Stream Pages
  When: URI Path starts with /watch/
  Then: Cache eligibility = Eligible for cache
        Edge TTL = Override → 5 minutes
        Browser TTL = Override → 5 minutes

RULE 3 — Bypass cache for API:
  Name: Bypass Status and API
  When: URI Path contains /status OR /api/ OR /cdn-check
  Then: Cache eligibility = Bypass cache

-------------------------------------------------------
PART 5: DEPLOY THE CLOUDFLARE WORKER
-------------------------------------------------------

1. Dashboard → Workers & Pages → Create Application → Create Worker
2. Name it: file2link-proxy
3. Click "Edit Code" → Delete all default code
4. Paste the entire content of cloudflare/worker.js
5. Update line: const ORIGIN = "https://yourproject.replit.app"
6. Update line: const BOT_DOMAIN = "yourdomain.com"
7. Click Save and Deploy

Connect worker to your domain:
Dashboard → Workers & Pages → file2link-proxy
→ Settings → Triggers → Add Custom Domain → yourdomain.com

-------------------------------------------------------
PART 6: UPDATE YOUR BOT CONFIG
-------------------------------------------------------

In Replit Secrets/Env Vars, update:
  FQDN = yourdomain.com
  HAS_SSL = True
  NO_PORT = True

Restart the bot. Streaming links will now use your domain.

-------------------------------------------------------
PART 7: TEST EVERYTHING
-------------------------------------------------------

1. Visit https://yourdomain.com/status → Should return JSON
2. Forward a file to bot → click Stream Now
3. Check response headers for CF-Cache-Status: MISS (first visit)
4. Refresh → CF-Cache-Status: HIT (served from edge)
5. Open a video → drag timeline → Network tab shows 206 range requests
